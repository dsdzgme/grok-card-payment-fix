## 先确认：卡是在哪一步被拒的

Grok 的扣费链路一共三步：填卡号，做一次小额验证（有时是 0 元或 1 美元的预授权），然后进入正式的周期扣费。链条不长，但每一步都可能被拦，多数人卡在第二步——卡信息填对了，验证那一下被拒。

被拒时先看付款页面给的错误提示，不同提示对应不同问题：

- **Do Not Honor / Restricted Card**：银行风控主动拒绝，最常见的一种；
- **Invalid Card**：卡号或有效期输入有误，检查后重试即可；
- **页面毫无反应，连验证短信都没收到**：交易在银行端就被挡下，根本没走到验证环节。

再补两个快速自查项。一是卡片类型：纯人民币借记卡基本过不了，它默认不支持外币结算；二是卡本身的状态：余额不足、额度用完或已停用的卡会被直接拒绝。按这个标准过一遍，多数人能自己定位问题出在哪个环节。

## 银行为什么要拦一笔小额订阅

理解风控的逻辑，后面跟银行打交道会顺利很多。核心是两个机制。

**商户类别码（MCC）的判定。** 每笔刷卡交易都带一个 MCC 码，用来标识商户类型。Grok 背后的支付通道通常被归为“电脑软件”或“数字服务”类。在银行的风控模型里，这类“非实体、异地、没有历史记录”的交易，特征和盗刷很像。银行宁可错杀，也不愿放过。

**定期扣款的授权要求。** 软件订阅在 Visa 和 Mastercard 的规则里属于“定期扣款”（Recurring Billing）交易，和单次消费不同，它需要商户与持卡人之间有明确的扣款授权。卡片没有预先开启“无卡交易”或“自动扣款授权”时，发卡行会出于合规直接拒绝请求。这是国际卡组织的安全机制在起作用，不是系统故障。

另外还有两个容易踩的坑：付款失败后短时间内反复提交，会被判定为异常行为，越试越容易被拉黑，连原本能用的卡都可能被连累；账单地址和开卡登记信息对不上（国家、邮编不一致），同样会被拒。

## 方案一：把银行该开的开关都打开

成本最低的办法，成功率也不低，建议先试这个。

主流银行的 App 里都有“卡片管理”或“安全设置”入口，找这几个关键词：**网上购物、海外交易、外币支付、无卡交易**，把状态从关闭改成开启。有个细节要注意：部分银行把“定期扣款授权”做成了单独开关，只开单次境外支付的话，第一个月扣费成功，第二个月续费还会再被拒一次。

App 里解决不了就直接打客服电话，沟通时把重点说出来：“我要进行一笔美元计价的境外软件订阅，系统提示 Do Not Honor，怀疑是商户类别触发了风控拦截，请帮我检查是否需要对该商户做临时授权，或者放宽境外无卡交易限额。”把逻辑讲清楚，客服就不用按“你的卡可能被盗刷”的流程走一遍，处理速度会快很多。

## 常见问题

**付款失败后马上重试有用吗？**

基本没用，还可能有害。短时间多次提交会触发风控，正确做法是先查清原因，改完设置或换卡之后再试。

**为什么开启了境外支付还是被拒？**

查两件事：账单地址是否和开卡信息一致，国家和邮编对不上就会被拒；网络 IP 所在地区和卡片国家是否匹配——平台会按卡片国家、IP 和账户地区做风控校验，对不上同样拒付。

**虚拟卡里要放多少钱？**

比订阅价格多 1~2 美元就够，这笔余量是用来通过小额预授权验证的。验证那一步过不去，后面都白搭。

**免费版够用吗？**

偶尔问几句还行。现在免费版的图片和视频生成基本不可用，文本对话也有比较严格的滚动限制，只要涉及生图、生视频或稍高频的使用，很快会碰到额度墙。

**代充怎么避坑？**
